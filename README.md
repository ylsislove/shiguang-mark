# 时光印 · Shiguang Mark

白色与淡紫色的本地照片水印工作台。React + TypeScript + Vite，所有照片处理在浏览器中完成，无需账号、服务器上传或远程图片服务。

## 功能

- 单张、多张、文件夹递归导入；支持拖放照片和文件夹、重复文件过滤。
- 读取 EXIF / IPTC / XMP 中的拍摄时间、GPS、地点名称、相机、镜头和曝光参数。
- 缺失信息不伪造。原始拍摄时间优先于数字化时间，文件修改时间不作为拍摄时间；按照片记录的当地时间显示，不自动转换时区。
- 精修照片可逐张关联原图，自动补全拍摄日期、地点和相机参数；可更换或移除关联，导出始终使用精修照片的画面和尺寸。
- 可单独补填日期与地点，或将当前值应用到整批照片；手动填写优先于读取结果，支持自定义文字。
- 六套模板：时光简记、胶片日期、旅行手札、相机名片、柔光铭牌、留白相纸。
- 四角定位、水平与垂直边距、字号、透明度、颜色控制；留白相纸固定在新增底部画布。
- 五套编辑器式布局：经典纵览、标签工作台、横向胶片、宽幅预览、左手工作台。模块可合并为标签组，也可拆成独立分区；支持左侧、右侧、底部停靠、顺序调整和区域宽高调整，布局及选中的标签自动保存在本机。
- 照片库在两侧用 ↑ / ↓、底部用 ← / →；手机支持左右滑动切图。输入框、布局对话框内的方向键不会切图；标签栏聚焦时方向键切换标签。
- 预览和导出共用绘制代码，可对比未加水印的照片。支持原尺寸 JPG / PNG / WebP、单张下载或批量 ZIP，超过约 150 MB 自动分包，导出可中止。
- 桌面工作台固定一屏，紧凑工具栏集成导入、布局切换和批量导出；照片库、拍摄信息及设置面板内部滚动。手机使用自然滚动布局。
- 只记住本机的模板样式与布局偏好，不保存照片、原图关联、地点和自定义文字。

## 浏览器与边界

网页不能根据输入的任意绝对路径自行扫描磁盘。请点击“选择文件夹”，在系统选择器中定位目标路径并授权。Chrome / Edge 的现代目录选择器需要 HTTPS；其他浏览器使用目录文件输入框，手机文件夹能力取决于系统，可改用相册多选。

支持 JPG、PNG、WebP、AVIF；HEIC / HEIF 取决于浏览器的原生解码能力。不支持的照片会明确提示转换，不会假装已导入。单张上限 6400 万像素、单边 16384 像素；内存不足会报告失败，可减少批次数量。导出过程逐张处理，生成的下载文件暂存在当前页面内存中。

GPS 可保留经纬度，也可点击“识别地名”查询附近名称并填入地点输入框。社交平台转存或 AI 精修常会丢失 EXIF，可通过“补充原图”恢复已有的拍摄信息，或者手动补填日期。

### 给精修照片补充原图信息

1. 导入精修照片，并选中需要补全信息的那张。
2. 在“拍摄信息”模块点击“补充原图”，选择对应的原始照片。
3. 自动提取可用信息，水印随即更新。已手动填写的日期和地点会保留；点击“恢复读取值”可改用原图信息。

每张精修照片单独关联原图，不按文件名猜测匹配。补充原图只在本机读取元数据，不上传照片，不替换精修画面，也不会向照片库新增一张。原图支持 JPG、PNG、WebP、AVIF、HEIC/HEIF、TIFF；提取信息无需浏览器解码原图像素。缺失的原图字段保留精修照片已有的值；完全没有可用拍摄信息时会提示，并保留已有的关联。刷新页面后需要重新导入并关联。

导出不会覆盖原文件，不复制原始 EXIF 等元数据；已选择写入水印的日期、位置和相机信息会直接出现在画面中。默认输出 JPG（透明图会以白色背景合成），PNG 为无损重编码。留白相纸增加底部画布，其余模板保持原图尺寸。

### 自定义工作台

点击顶部的布局按钮选择预设。“标签工作台”把拍摄信息与水印设计合并到右侧，通过标签切换；其他预设保留独立分区。所有预设都把拍摄信息放在侧栏，中间用于画面预览。

- 拖动模块标题或单个标签到另一模块的**中间**，合并成标签组；松手后激活刚移入的标签。
- 拖到模块的**上 / 下边缘**，创建独立的上下分区；底部区域使用左 / 右分区。把标签拖到自己所在组的边缘，也能拆开。
- 拖到预览区边缘的高亮目标，独立停靠到左侧、右侧或底部。拖动过程中会显示合并、分区和松手结果提示，Esc 可取消。
- 不方便拖动时，在布局设置或模块移动菜单中选择“组合方式”：与其他模块合并标签，或恢复“独立分区”。前移 / 后移可调整标签或独立分区的顺序。
- 点击标签切换内容；标签聚焦时可用方向键、Home / End 切换，不触发照片切换。切换标签不清空当前编辑值。

拖动侧栏边缘、底部区域上边缘可改变区域大小，键盘聚焦分隔条后可用方向键调整。标签组、选中的标签、顺序及区域尺寸保存在本机，旧版布局自动迁移。切换预设即可恢复。

手机按预览优先自然滚动，保留标签组及切换能力；可通过布局设置合并或拆分模块，桌面停靠位置继续保留。

### 地名与经纬度

在“拍摄信息”中点击“识别地名”，使用 [Photon 公开服务](https://github.com/komoot/photon#demo-server)查询当前照片坐标并默认填入地点输入框。点击前页面明确说明数据去向：**仅发送纬度、经度和结果数量，不发送照片、文件名或其余 EXIF**。不自动查询整批照片，不读取设备当前位置。图片处理和导出仍在本机进行。

地名可修改；“显示经纬度”使用照片或关联原图的 GPS，“显示地名”恢复已修改的名称。已有手动输入不被异步结果覆盖，可以点击“采用识别地名”使用查询结果。更换原图后，旧坐标的地名和晚到结果不会应用到新坐标。

数据来自 [© OpenStreetMap 贡献者](https://www.openstreetmap.org/copyright)。Photon 返回附近名称，可能包含道路、行政区域或当地语言；它不是精确拍摄位置证明。公开服务允许合理用量，但不保证可用性：当前仅用户点击触发，串行请求至少间隔 1.1 秒，页面内缓存最多 256 个坐标，12 秒超时，失败可重试或手填。缓存不写入浏览器持久存储。较大规模使用应配置自建或有服务保障的提供方；请求地址集中在 `src/geocoding.ts`。

## 本地开发

Node.js 22.16+（CI 使用 Node.js 22），npm。

```sh
npm ci
npm run dev
npm test
npm run build
```

预览地址默认 `http://127.0.0.1:5178`。`dist/` 是完整静态站点，可由 Nginx、对象存储或静态托管平台提供。网站的交互由浏览器执行，因此不需要应用服务器。

## 发布

正式站点：[mark.aayu.today](https://mark.aayu.today)。域名解析与 HTTPS 配置参见 [部署说明](docs/deployment.md)。自动检查工作流在 push 和 pull request 时运行测试与构建。

遵循项目要求，正式部署使用腾讯云，未启用 GitHub Pages。技术上完整核心功能也适用于 GitHub Pages，因为它们无需服务器端运行；选择文件夹仍需要用户授权。

## 项目结构

- `src/model.ts`：元数据标准化、日期、设置与导出文件名。
- `src/photos.ts`：图片解码、缩略图、EXIF 和文件夹遍历。
- `src/render.ts`：预览和导出共用的 Canvas 绘制。
- `src/layout.ts` / `src/DockWorkspace.tsx` / `src/dock.css`：停靠布局、预设、拖动、拉伸与响应式界面。
- `src/geocoding.ts`：地名查询、去重、缓存、限速和错误处理。
- `src/App.tsx`：照片库、元数据编辑、设计面板、导出与键盘交互。
- `tests/model.test.ts`：时间真实性、坐标、比例定位、导出路径测试。

依赖：React、exifr、fflate、lucide-react。个人照片、密钥、部署凭据均不属于源码仓库。
